# ModelEvaluating

Demo đo tốc độ YOLO26n phát hiện người trên CPU.

1. Cài thư viện bằng `python -m pip install ultralytics opencv-python`.
2. Đặt `yolo26n.pt` và video mẫu tên `Intrusion.mp4` cạnh script.
3. Chạy `python test_yolo.py`.

[Nguồn model YOLO26](https://docs.ultralytics.com/models/yolo26/)
